# Dashboard de Gestão e Análise de Dados

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma dashboard para visualização, acompanhamento e análise de informações empresariais, com foco na gestão de vendas, controle de estoque e apoio à tomada de decisões.

A solução foi desenvolvida como parte de um projeto acadêmico de Modelagem de Banco de Dados, buscando demonstrar como a integração entre banco de dados, desenvolvimento web e Business Intelligence (BI) pode contribuir para uma gestão mais organizada e eficiente.

## Objetivos

- Centralizar informações importantes para a gestão.
- Facilitar a visualização de indicadores e resultados.
- Acompanhar informações relacionadas às vendas e ao estoque.
- Auxiliar na identificação de problemas e oportunidades.
- Demonstrar como os dados podem apoiar a tomada de decisões.

## Funcionalidades

- Dashboard com indicadores de gestão.
- Visualização de informações de vendas e faturamento.
- Acompanhamento de produtos e estoque.
- Gráficos para facilitar a interpretação dos dados.
- Análise de informações para apoio à gestão empresarial.

 ## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual.
- **JavaScript:** funcionalidades e interatividade.
- **MySQL:** gerenciamento e armazenamento dos dados.
- **SQL:** criação, manipulação e consulta das informações.

  ## Banco de Dados

O projeto utiliza MySQL para estruturar e armazenar as informações necessárias à gestão.

Os arquivos SQL disponibilizados no repositório contemplam a criação das tabelas, inserção de dados e consultas utilizadas no desenvolvimento e na demonstração do projeto.

## Business Intelligence e Inteligência Artificial

Além da implementação do banco de dados e da dashboard, o projeto apresenta possibilidades de utilização de Business Intelligence (BI) e Inteligência Artificial (IA).

O BI pode transformar os dados armazenados em indicadores, gráficos e relatórios, facilitando o acompanhamento do desempenho empresarial.

Como evolução futura, a IA poderá auxiliar na identificação de padrões, análise de movimentações, identificação de possíveis inconsistências e previsão de necessidades de reposição de estoque.

- **Git e GitHub:** versionamento e hospedagem do código.
