# Dashboard de Gestão e Análise de Dados

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma dashboard para visualização, acompanhamento e análise de informações empresariais, com foco na gestão de vendas, controle de estoque e apoio à tomada de decisões.

A solução foi desenvolvida como parte de um projeto acadêmico de Modelagem de Banco de Dados, buscando demonstrar como a integração entre banco de dados, desenvolvimento web e Business Intelligence (BI) pode contribuir para uma gestão mais organizada e eficiente.

## Objetivos

- Centralizar informações importantes para a gestão.
- Facilitar a visualização de indicadores e resultados.
- Acompanhar informações relacionadas às vendas e ao estoque.
- Auxiliar na identificação de problemas e oportunidades.
- Demonstrar como os dados podem apoiar a tomada de decisões.
